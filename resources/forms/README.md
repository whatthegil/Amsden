# Library forms

`access-permission-waiver.pdf` — the CSPC Library's official Access Permission
Waiver. Authors download it from **My Uploads** once an admin approves their
bluebook (status *Awaiting Waiver*), print and sign it, and hand it in to the
library. The admin then clicks **Waiver Received** and the bluebook is posted.

Replace the file with the library's current form whenever it changes; keep the
file name. It is committed to the repository so every deploy ships it. If it is
missing, the download button tells the author to get a copy from the library.
